# This is an implementation of NSFW Detection for ComfyUI

## Project Overview

This project is designed to detect whether images generated by ComfyUI are Not Safe For Work (NSFW). It uses a machine learning model to classify images and then routes them to different outputs based on the classification.

## Install

1. Clone this repo into custom_nodes directory of ComfyUI location

2. Run pip install -r requirements.txt

## Usage

The `NSFWDetection` node processes a batch of images and classifies each one as SFW (Safe For Work) or NSFW (Not Safe For Work) based on a confidence score.

### Inputs

The node accepts the following inputs:

-   `image`: An image or a batch of images to be classified (Type: `IMAGE`).
-   `score`: The confidence threshold for classifying an image as NSFW (Type: `FLOAT`). If the model's NSFW confidence score for an image is equal to or greater than this value, it's considered NSFW. Otherwise, it's considered SFW. (Default: `0.9`, Min: `0.0`, Max: `1.0`).

### Outputs

The node provides two output image batches:

-   `SFW_IMAGES`: (Type: `IMAGE`) This output contains all images from the input batch that were classified as SFW (i.e., their NSFW score was below the `score` threshold).
-   `NSFW_IMAGES`: (Type: `IMAGE`) This output contains all images from the input batch that were classified as NSFW (i.e., their NSFW score met or exceeded the `score` threshold).

If no images fall into a particular category (e.g., no NSFW images are detected), the corresponding output will be an empty image batch.

### Workflow

This node no longer saves images directly. Instead, you should connect its outputs to other nodes to handle the SFW and NSFW images. A common workflow is to connect each output to a separate "Save Image" node.

## Example

A typical workflow would be:

1.  Generate images using your preferred method (e.g., KSampler).
2.  Connect the output of the image generation node to the `image` input of the `NSFWDetection` node.
3.  Set your desired `score` threshold on the `NSFWDetection` node.
4.  Connect the `SFW_IMAGES` output of the `NSFWDetection` node to a "Save Image" node (or any other node for further SFW image processing).
5.  Connect the `NSFW_IMAGES` output of the `NSFWDetection` node to a different "Save Image" node (or any other node for further NSFW image processing, like blurring or discarding).

This setup allows you to manage SFW and NSFW images separately according to your needs.
