# This is an implementation of NSFW Detection for ComfyUI

## Project Overview

This project provides a `NSFWDetection` node for ComfyUI. It uses a machine learning model to classify images as SFW (Safe For Work) or NSFW (Not Safe For Work). Based on this classification, the node saves the original images directly to designated SFW or NSFW directories, with a key feature being the preservation of original image metadata.

## Install

1. Clone this repo into `ComfyUI/custom_nodes/` directory.
2. Run `pip install -r requirements.txt` from within this cloned directory to install necessary dependencies.
3. Restart ComfyUI.

## Usage

The `NSFWDetection` node processes a batch of images, classifies each, and then saves them to disk.

### Inputs

The node requires the following inputs:

-   `image` (IMAGE): The batch of images to be processed. This is typically the output from an image loader or a generation node (e.g., KSampler).
-   `score` (FLOAT): The confidence threshold (0.0 to 1.0, default 0.9) for classifying an image as NSFW. If the model's NSFW confidence for an image meets or exceeds this score, it's considered NSFW.
-   `file_paths` (STRING, multiline): This is a crucial input for metadata preservation. It must be a **newline-separated list of full file paths** corresponding *exactly* in order and number to the images in the `image` batch.
    *   **Purpose**: These paths are used to re-open the original image files from disk before saving. This allows the node to read and preserve metadata (like EXIF, ICC profiles, and PNG textual chunks, which often include ComfyUI workflow data).
    *   **Example Format**:
        ```
        /path/to/your/image_001.png
        /path/to/your/image_002.jpeg
        /path/to/your/image_003.png
        ```
    *   **Obtaining File Paths**: Some image loader nodes (e.g., certain batch loaders) might provide filename or filepath outputs. You may need to use a text concatenation node or a simple custom script node to format these paths correctly into a single newline-separated string. If your loader doesn't output paths, you might need to manually prepare this list or use a workflow that ensures paths are available.
-   `sfw_output_dir` (STRING): The directory path where SFW images will be saved. (Default: `output/sfw`)
-   `nsfw_output_dir` (STRING): The directory path where NSFW images will be saved. (Default: `output/nsfw`)

### Outputs

This node has **no direct outputs**. Its function is to save the classified images directly to the file system.

### Core Functionality

1.  **Classification**: Each image in the input batch is classified as SFW or NSFW using a pre-trained model and the specified `score` threshold.
2.  **Directory Creation**: The specified `sfw_output_dir` and `nsfw_output_dir` will be created automatically if they do not exist.
3.  **Direct Saving**:
    *   Images classified as SFW are saved into the `sfw_output_dir`.
    *   Images classified as NSFW are saved into the `nsfw_output_dir`.
4.  **Metadata Preservation**:
    *   Using the corresponding path from the `file_paths` input, the node re-opens the original image file from disk.
    *   It then attempts to preserve important metadata from this original file, including:
        *   EXIF data
        *   ICC color profiles
        *   PNG textual chunks (e.g., `parameters`, `workflow`, `prompt` commonly embedded by ComfyUI and other image generation tools).
    *   This means the saved SFW/NSFW images will retain as much of their original metadata as possible.
5.  **Unique Filenames**: Images are saved with a unique filename, generated by prepending a timestamp to the original filename (e.g., `20231027_123456789000_original_filename.png`). This prevents overwriting files.

## Example Workflow

1.  **Load Images**: Use an image loader node (e.g., "Load Image Batch" or similar) that provides access to the file paths of the loaded images.
    *   *Crucial Step*: Ensure you can get a list of full file paths for the images being loaded.
2.  **Prepare `file_paths` Input**:
    *   If your loader node outputs a list of filenames, you might need a utility node (like a text concatenation node, or a simple custom script) to format these into a single string, with each path on a new line, as shown in the `file_paths` description above.
    *   Connect this formatted string of file paths to the `file_paths` input of the `NSFWDetection` node.
3.  **Connect Images**: Connect the `IMAGE` output of your loader node to the `image` input of the `NSFWDetection` node.
4.  **Configure NSFWDetection Node**:
    *   Set the desired `score` threshold.
    *   Specify your `sfw_output_dir` and `nsfw_output_dir`.
5.  **Run Workflow**: Execute the workflow. The `NSFWDetection` node will classify the images and save them with their metadata to the appropriate directories. Since there are no outputs from this node, you would typically check the specified output directories on your file system to find the saved images.

This setup ensures that images are sorted into SFW/NSFW folders while retaining valuable original metadata.
